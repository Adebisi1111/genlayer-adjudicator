GenLayer Intelligent Contract

Agent Payment Adjudicator

A reusable dispute-resolution primitive for the agentic economy. A payer deposits contested funds; an LLM judge (run through GenLayer's equivalence principle) decides delivery, then value is routed to the agent or refunded to the payer.

How it works

1

Open dispute (payable)

open_dispute(agent, service_url, claim) Payer deposits the contested amount into the contract. State is stored as a Dispute record.
2

Fetch live service state

gl.nondet.web.render(service_url) The contract pulls the actual service output at resolution time — not a stale claim.
3

LLM judgment via equivalence principle

gl.nondet.exec_prompt(...) → gl.vm.run_nondet(...) Leader and validators each evaluate delivery independently; outputs must agree for consensus.
4

Route the value

gl.get_contract_at(...).emit_transfer(value=...) DELIVERED → pay agent. NOT_DELIVERED → refund payer. Double-resolution is rejected.

Two possible outcomes

✓ Service delivered

  • LLM judge returns DELIVERED
  • Contract emits transfer to agent
  • Dispute marked resolved

✗ Service not delivered

  • LLM judge returns NOT_DELIVERED
  • Contract refunds payer
  • Dispute marked resolved

State design

Dispute dataclass — id: str, payer: str, agent: str, amount: u256, service_url: str, claim: str, status: str, verdict: str. Disputes held in a TreeMap; counter is a u256. Clear, native GenLayer storage — no thin wrappers.

Verified

3 direct-mode tests pass (refund-on-non-delivery, pay-agent-on-delivery, double-resolution revert) alongside the boilerplate suite — 46 tests total.
